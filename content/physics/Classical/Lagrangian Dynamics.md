### Subjects in Lagrangians dynamics
- Lagrangian dynamics is a deep subject and is really an amalgamation of many different branches of mathematics and physics
- The main two branches are [[Variational Calculus]] and Differential Topology

### Overall structure
- Lagrangian dynamics begins by assuming nothing about the system. There are no forces, energies, etc. 
- Instead, a system will provide something called a **Lagrangian**, which will be used to solve for something called a **system path**
	- Before that, there is something called a **configuration**, denoted $q$. This $q$ represents the state that the system can take at any given time. The **space of all configurations** is denoted $Q$
	- With Lagrangian Dynamics, we select two **boundary values** for the configuration. That is, we observe the system at two different times: $q(t_0)$ and $q(t_1)$. We then try to solve for the path the system took to go from $q(t_0)$ to $q(t_1)$. 
	- $Q$ is actually a <b><ur>Smooth Manifold</b></ur>!!! This allows us to build a lot of neat structures and is even useful for the [[Hamiltonian Formalism]]
- This Lagrangian will eventually lead to a second order differential equation that can be used to solve for the system path
