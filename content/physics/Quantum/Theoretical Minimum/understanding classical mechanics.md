### Building foundations with Classical mechanics
- Both classical and quantum mechanics describe a set of states of a system
- A system can possess various different states, one at a time
	- For example: a system (die) can be in the state given by the set
		$A = \{1,2,3,4, 5, 6 \}$
	- A coin can be given by
		$C = \{H,T\}$
- Each entry in the set denotes a possible state of the system, where the set denotes the total values the system can possess
	- In classical mechanics, this allows us to build off of set theory
		- We can take things like "and" and "or" operations
	- the mathematics of set theory perfectly describe the set of all states of a classical system
