Consider the example
$$
\frac{\mathbb{Z}[x]}{(x^2-3, 2x+4)}
$$
so in this case, we can replace $x^2$ with $3$. Also note that we cannot replace $2x+4$ with $x+2$ because we cannot divide by 2 in $\mathbb{Z}$. therefore $(2x+4) \not \subset   (x+2)$, so everything in the denominator is set to 0: $x^2-3=0, \, 2x+4=0$ (quotienting by these elements corresponds to setting elements of this form to the identity 0). 

so starting with $\frac{\mathbb{Z}(x)}{(x^{2}-3)}$ would build a set that resembles only degree one polynomials
So 
$$
	\frac{\mathbb{Z}[x]}{x^2-3}\leftrightarrow \{ a+bx : a, \, b \in \mathbb{Z} \}.
$$
In fact, the set $\{ a+bx \}$ forms a ring. what is the product in this new ring?
$$
	(a+bx) * (c+dx)=ac + adx + bcx + bdx^2=ac+3bd +(ad+bc)x
$$
now, we quotient by $2x+4 \implies 2x=-4$
Under this quotient, we have that $(4+2x)*(a+bx)=0 \to (4a-6b)+x(4b+2a)=0$ for every $a, b \in \mathbb{Z}$. 


### General notes for the final
- To show that two rings are not isomorphic (or just to get a feel fo the rings that you are working with)
	- Look for if they are a domain or a field. if one of the rings have zero divisors while the other one does not, they cannot possibly be isomorphic
	- Quotient out by different things. for example
		$$
			\frac{\mathbb{Z}[x]}{x^{2}+7} \not \cong \frac{\mathbb{Z}[x]}{2x^{2}+7}
		$$
	- a way to see this is is by arguing by contradiction. if the two rings were indeed isomorphic, then
		$$
			\frac{\mathbb{Z}[x]}{(x^{2}+7, 2)} \cong \frac{\mathbb{Z}[x]}{(2x^{2}+7, 2)} \implies \frac{\mathbb{F}_{2}}{x^{2}+1} \cong \{0\}
		$$
	- which is just not true
- If a group $G$ is cyclic and if you have two subgroups $H \leq G$ and $K \leq G$, then 
	$$
		\lvert H \cap K \rvert = \text{gcd}(\lvert H \rvert, \lvert K \rvert  )
	$$
- if your ideal is generated by two elements, see if you can reduce the ideal to just one element and see how that simplifies that quotient
- remember that quotienting by a linear term is the same as substitution (substitution principle)
- review all the different groups and rings that you know and see if you can build homomorphisms / isomorphisms from these groups
- If the ring that you are staring with (denoted $R$) has zero divisors, then a lot of the polynomial algebra that we know from HS doesn't work in $R[x]$.
