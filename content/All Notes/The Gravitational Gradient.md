### Basic intuition:
- Imagine that you had an apparatus that measures the force it experiences
	- Think about one of those apparatuses that when you pull on, it measures the force that it experiences
- Will such an object be able to measure it's own acceleration that it experiences as it moves in a gravitational field?
	- no!
	- this is because the entire object measures the same force and hence has the same acceleration, so there is no relative acceleration or force
	- it doesn't think that it's moving because it is in it's own reference frame

### Necessity of the gravitational gradient
- the best that you can do is to measure the change in force that an object can experience in the gravitaitonal field
- this is the gravitational gradient: it measures the change in force per unit distance
- $$\mathbf{F} = \frac{GmM \mathbf{r}}{|\mathbf{r}|^3} \rightarrow g = \frac{GM}{\mathbf{r}^2}$$
- Gradient is essentially the change in gravity over seperation
- $$g' = \frac{\Delta g}{\Delta r} \rightarrow GM \times \frac{d}{\mathbf{r}^3}$$

### Connections with electric dipoles:
- We know that the electric field of the dipole also scales based on $\frac{1}{\mathbf{r}^3}$ 
- $$\mathbf{E} = 2kQ \ \frac{\mathbf{s}}{\mathbf{r}^3}$$
